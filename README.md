# 📝 Task Manager App

A modern Task Manager application built using **HTML**, **CSS**, and **Vanilla JavaScript**. This project helps users manage daily tasks efficiently with features like adding, editing, deleting, completing, filtering, and tracking task statistics.

---

## 🚀 Features

### Task Management

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🔄 Toggle completed/uncompleted status

### Task Filtering

- 📋 View all tasks
- ✔️ View completed tasks
- ⏳ View pending tasks
- 🧹 Clear all completed tasks

### Statistics Dashboard

- 📊 Total Tasks Counter
- ✅ Completed Tasks Counter
- ⏳ Pending Tasks Counter

### User Experience

- 🌙 Dark Mode / Light Mode
- 📱 Responsive Design
- 🎨 Modern UI Design
- 🔔 Empty State Handling

## ⚙️ How It Works

### Adding Tasks

Users can create new tasks by entering task details and selecting a category.

### Editing Tasks

Users can update task information before completion.

### Completing Tasks

Completed tasks receive a visual indicator and are automatically reflected in statistics.

### Filtering Tasks

Tasks can be filtered based on:

- All Tasks
- Completed Tasks
- Pending Tasks

### Statistics

The application automatically updates:

- Total Tasks
- Completed Tasks
- Pending Tasks
